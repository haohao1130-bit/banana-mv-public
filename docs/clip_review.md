# 丹藥檢查：無聲毛片與批次回爐

每段完成後，專案頁的「丹藥檢查」顯示無聲毛片。影片使用 preload=none，只有播放時才讀取；狀態輪詢保留同一個播放器，不會一直重建或重載。

可以邊生成邊預覽、勾記需要重拍的段落。待這爐完成，或按停止並等當前段落完成後，再按「將所選丹藥回爐重煉」。也可全選／清除。只有已完成且檔案有效的段落可以回爐，尚未完成的工作使用原有「續跑」。

## 回爐的範圍

- 只重新生成勾選的段落，按時間排序。其他毛片不重新採樣。
- 留空修改建議時沿用已保存提示詞，只換該段尚未使用的 Seed；填寫時 9B 只局部修正本段原稿。保留原時長、模型與生成設定，不改全曲計畫或狀態帳本。
- 全部勾選段落成功後，才採用這批新版並重新合成一次完整 MV。合成先使用候選版本產生成品，成功後才替換目前毛片。
- 中途生成或合成失敗，保留原本採用的毛片與成片。已成功的新版本保留在各段版本選單，可單獨預覽、採用；未開始的候選標為 cancelled，不會偷偷續跑。
- 「目前這段完成後停止」也適用回爐：當前候選完成後停止，不自動替換目前版本。已完成候選仍可採用。

每段都有「局部修改建議」欄位，最多 3000 字，以目前採用版為基底；只有勾選段落的意見會送出。草稿保留於同一瀏覽器，輪詢不清空。修稿失敗不會進入該段 H3 採樣。

各段的版本選單可比較「初煉版」和「回爐版」，顯示實際 Seed。選好後按「採用此丹」會重新合成，不重新生成；也可切回初煉版。上方專案 Seed 仍是初始基準值，各版實際 Seed 看該顆丹的說明。

若專案還有其他未完成段落，可回爐已完成段落；此時不宣稱整支完成，不產生新的完整成片，後續仍需續跑。

## 末幀接續

連續勾選的段落，後一段使用本批前一段新版的末幀；未勾選的前段使用目前採用版本。未勾選的後段不會自動失效或重跑，請在採用後檢查接點，需要時自行勾選回爐。規劃中的角色、事件與狀態不因此改寫。

## 無聲預覽與對嘴

毛片直接串流既有的 `*_part.mp4`，沒有音訊流，不為預覽另外轉碼、加原曲或跑生成。播放器也預設靜音。Range 與 HEAD 沿用既有影片傳輸，因此可拖動播放進度。

生成／回爐仍以原曲或已提供的隔離人聲，按原段落起點和模型長度裁切後接到 H3 的 `drive_audio`，維持 `audio_mode=lock_source` 與音訊去噪強度 0。最後整支合成才混入一次原曲。毛片無聲不會關閉生成時的對嘴條件；換 Seed 後的實際對嘴品質仍可能改變，需要看片。

## 保存與 API

候選毛片、原始模型輸出、提示詞、workflow 存在專案內 `takes/段落編號/版本編號/`。初煉版保存在 original。有修稿時另存 repair_request.json、repair_raw.txt；採用時同步目前段落提示詞與 workflow。`status.json` 保存版本、Seed、修改意見、目前採用版本與回爐進度，沿用專案既有的持久保存方式，不刪除舊版本。

- `GET /api/mv/status?id=...`：附加各段 preview、takes 與 selected_take。
- `GET /api/mv/clip?id=...&index=0&take=original`：無聲毛片。index 從 0 起算；current 代表目前採用毛片。
- `POST /api/mv/retake`：`{"id":"...","indices":[1,2]}`，重拍第 2、3 段；可加 `"instructions":{"1":"局部修改意見"}`，索引從 0 起算。正常全成功後自動採用並合成。
- `POST /api/mv/select-take`：`{"id":"...","index":1,"take":"版本編號"}`，採用已完成版本，不呼叫 GPU 生成。

回爐、採用、原本的啟動與續跑共享同一把工作鎖。回爐先檢查 ComfyUI 佇列；外部工作尚未清空時不插隊。所有段落與版本查找皆經固定路徑和已保存 metadata，不接受任意檔案路徑。

## 驗證限制

離線測試覆蓋多選去重、只採樣指定段落、生成音訊連接、換 Seed、批次失敗與停止、只合成一次、舊版還原、相鄰末幀接續、狀態帳本不變、啟動方式共用工作鎖、Range/HEAD 與路徑限制。另用 ffmpeg 產生測試影片，確認串流毛片只有 video stream。

前端模擬測試覆蓋多選送出、忙碌狀態、保留播放器和勾選、版本預覽與採用。沒有實際 GPU 重拍或 Colab 手機瀏覽器驗收；瀏覽器視覺測試仍受目前環境限制。


## 完整作品版本

每次成功合成都新增 `final_vNNN.mp4`，`final.mp4` 為目前版本。舊專案首次回爐先保存現有成片；回爐或重新選丹後產生第二、第三版，舊完整 MV 與舊毛片均保留。介面「完整作品版本」可分別下載，`GET /api/mv/file?id=...&version=1` 讀取已登記的第 1 版。只有部分段落完成時不產生完整版本。主要位置是當次工作資料夾，videos 僅為另存副本。
