# 🍌 BANANAMV｜玩家操作手冊（RTX 5070 本機版）

這份手冊是給**想製作 MV 的一般使用者**看的，對應 RTX 5070 本機分支的前端；不需要懂程式碼。若使用的是另一個版本（例如 Colab 正式版），按鈕與回爐流程可能不同，請以實際介面為準。

前端頁面右上角有 **「📖 操作說明」** 和 **「🤖 一鍵複製給 AI」**：前者自己看，後者複製後貼進 ChatGPT 或其他 AI，它就能依這份玩法幫忙構思故事、填欄位、按步驟操作。AI 不會因為貼上這份指南就能看見或控制你的前端。

## 1. 準備藥材：照片和歌曲

先打開已可使用的本機 BANANAMV 前端，準備原歌曲與人物、場景、道具等參考圖片。

- **圖片固定編號**：每格選一張，第一格就是 `@圖片1`，第二格是 `@圖片2`。刪除某格不會自動改掉其他圖片編號。圖片用來辨認人物與物品，不代表必須照著照片的表情或姿勢演出。
- **圖片數量**：獨立分段最多 9 張；末幀、末五幀接續最多 8 張。不需要參考圖的配角可以用文字描述，但不要捏造 `@圖片N`。
- **原歌曲**：上傳實際要製作的音檔，長度最多 5 分鐘。新手先試短片段。
- **選填**：可貼全曲歌詞、匯入 UTF-8 SRT、上傳隔離人聲或純音效軌。SRT 的時間從這次上傳的歌曲起點計算；可寫 `[S1]`、`[S2]`，並在劇本說明聲部對應人物。隔離人聲／音效要和原曲同起點、同長度。歌詞不會自動生成字幕，SRT 不代表額外台詞。

## 2. 在「想拍什麼」寫故事

先寫**人物身分、誰演唱、場景位置、事件先後、故事結果**，再描述風格或鏡頭。事件主導鏡頭，不強迫每句歌詞對應一個鏡頭。

例如：

```text
@圖片1 是舞台主唱，負責演唱與對嘴。
@圖片2 是地下拳擊場的挑戰者，只負責比賽，不演唱。
舞台與拳擊場是兩個獨立地點，依音樂節奏交錯剪接。
挑戰者主動進攻，拳王有防守和反擊，最後在決勝段分出勝負。
拳王、觀眾與裁判由文字描述，不引用不存在的圖片。
```

人物換裝、場景切換和重要道具要說清楚發生在哪個事件。若要完整收尾，選「**本次音檔演完完整故事**」；若只拍其中一段，選「**只拍故事片段，保留後續**」。

## 3. 選生成設定

| 前端欄位 | 一般用法 |
| --- | --- |
| 生成模式：獨立分段 | 各段使用同組參考圖，適合跳接與獨立構圖。 |
| 生成模式：末幀接續 | 下一段接前段實際尾幀，適合連續動作及故事。 |
| 生成模式：末五幀接續｜實驗 | 多幀接續，需留意資源用量及畫面接點。 |
| 每段長度 | RTX 5070 12GB 建議從 **5 秒** 測試；10／15 秒需視顯存而定。 |
| 生成解析度 | 建議先用 **480P**；720P 可能需要更多顯存。 |
| 影片風格、動作強度 | 依歌曲選演唱、劇情、動作等；高動態不保證更準確。 |
| 使用本地 9B 自動導演 | 勾選時 Python 分配事件，9B 逐段安排表演與運鏡；取消後依貼入劇本切段直接交 H3。 |
| 音樂／音樂結構分析 | 可幫忙推估節奏、強弱與段落，**不能辨識真實歌手聲部**。 |

## 4. 先審丹方，還是直接開拍？

- **「先搓丹方」**：先看各段事件及故事安排，確認後按 **「丹方無誤，開爐」**。此時才開始生成影片。
- **「直接煉丹」**：略過人工審閱這一關，規劃後直接生成。

生成中可在「專案與生成紀錄」查看目前段落、進度與各段實際提示詞。**進度數字是已完成段數**，不是 GPU 每一步的百分比。逐段預覽、對嘴、角色與接點仍需要真人看片確認。

## 5. 5070 連續模式的正確回爐流程

例如第 4 段有問題，新的第 4 段拍成 V2：

1. 仍在生成時，按 **「目前這段完成後停止」**，讓當前片段收尾後停爐。
2. 找到第 4 段，在「丹藥檢查」按 **「重配丹方（9B 重寫）」**，取得新提示詞；可再手動修改。
3. 按 **「依此提示詞回爐這一段」** 才會真正產生 V2。單按重配丹方**不會生成影片**。
4. 預覽 V2，滿意後按 **「正式採用此版本」**。只用下拉選單預覽 V2，**不等於正式採用**。
5. 因第 5 段起使用舊第 4 段尾幀，必須按 **「從本段尾幀續拍第 5 段（9B 重寫）」**，讓所有後續畫面按新版接點重新生成。

**第 4 段 V2 + 舊第 5 段 V1 不一定接得起來**。舊後段會保留為歷史毛片，但不能在新的連續時間線裡混合採用。**5070 連續模式不使用「僅改這段，保留後續」與「確認凝丹」**；兩者是另一種舊流程。

若改的是**最後一段**，沒有後續需要重拍，按 **「合成正式新版全片」** 即可。

## 6. 獨立分段的回爐流程不一樣

如果選的是「獨立分段」，仍可勾選一段或多段重新回爐，預覽後按 **「選用此丹」**，最後按 **「確認凝丹」** 合成。這種方式不會把下一段強制視為舊尾幀，**不要和 5070 連續模式混淆**。

無論哪種模式，V1、V2 等候選影片與舊成片原則上保留，可從版本選單預覽；某個 Take 正在下拉選單顯示，不代表它已被正式採用。

## 7. 續跑、作品版本與後製

- 有保存的專案，從「已保存的專案」選擇，再按 **「續跑未完成段落」**。如果已正式採用中途新版，就要從新版尾幀接拍後續。
- 完整作品在「**母片 · 成片操作**」預覽／下載，「**完整作品版本**」有歷史成片。舊版仍可另行下載，不當作新版接續的正式內容。
- **修臉、1080P** 都是選用的後製功能。前端顯示可操作時才使用；新母片做完後要核對輸出是否來自這一版。
- 前端斷線不代表生成真的停止；先重新檢查專案狀態，避免重複開爐。請勿同時在多個地方操作同一專案。

## 8. 一鍵把玩法交給你的 AI

點頁面頂端 **「🤖 一鍵複製給 AI」**，然後貼進 ChatGPT 或其他 AI：

- 它會讀到角色與素材填法、故事設定、模式差異、兩種煉丹入口、回爐選版、續拍與成片位置。
- 請它**每次只教你接下來 1～3 個動作**；按鈕要符合目前畫面。看不到畫面時，請它先問你目前第幾段或請你貼截圖。
- 指南只教**玩家怎麼玩**，不包含維修程式、操作 GitHub、執行命令或修改模型；也不會把你本人的照片和歌曲自動複製給 AI。

如瀏覽器拒絕剪貼簿權限，畫面會顯示並選取指南文字，可自行複製貼上。
