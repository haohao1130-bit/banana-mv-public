# Banana MV：一次分戲，逐段原生導演

新任務使用 director_schema=5。先按選定的 10／15 秒分配劇情，再逐段產生完整 H3 拍攝稿。正常模型呼叫為一次全片規劃，加每段一次原生改寫；交稿或媒體引用失敗才使用既有有限次重試。

## 全片規劃

規劃器收到完整故事、原始編號參考圖、歌曲時長、音樂強弱及已提供的歌詞／SRT。共用設定擷取使用者原文的世界、角色／素材分工與各自場景設定，不摘要外觀、不重設世界。使用者只有主軸時，故事導演沿主軸展開具體可拍的角色行動、互動與平行線，再分配到各段；已提供完整劇本時，保留原有動作、因果和指定終章來分配，不重新編寫。兩者都不是摘要或機械剪貼原文。保留重要動作、對象、道具、因果、指定結果與音樂時間點。長動作可跨段分配；保留使用者已指定的特殊鏡頭，不另外替每段編一份鏡頭清單或狀態帳本。

交稿使用 SETUP、CLIP、END 純文字邊界；Python 保存 director_plan.json，不要求 9B 生成 JSON。規劃保存後續跑沿用；壞快取不偷偷重做。共用設定不放劇情回顧、未來事件或結局；當段大綱使用當下狀態，例如「英雄已變身」，不重述取得力量的過程。保留原故事因果、明確時間點與指定結果，不要求每段演完一場小短劇。

## 當段自動導演

各自獨立的場景以剪輯交錯，不合併場地或把兩地角色硬放同框；角色造型依實際參考圖，不能用物種或物件的泛稱代替。

9B 收到原生 Ref2VA 寫作指南、原始參考圖、共用設定、當段大綱、可見時長、當段音樂資訊與收尾條件。它第一次決定本段鏡頭、運鏡和剪輯，輸出完整原生 H3 提示詞，再直接生成。

下游沿用 Toybox 的原生增強任務定位：短篇 Ref2VA 增強 system 後接官方指南；使用者訊息以明確時長與 Original prompt 提供共用設定、本段劇本，要求依內容與節奏自主選鏡及安排切點。局部 SRT、音樂證據與收尾另列為補充 context。這只改變改寫輸入包裝，不重新分戲、不增加模型呼叫。逐鏡構圖、光線與運鏡依官方指南自然寫進 detailed_description；不採固定鏡頭清單。真實 9B／H3 攝影品質仍需同一劇本實測；既有保存稿不會因更新程式而自動重寫。

當段輸入不含完整故事、前段提示詞、前段事件回顧或全曲歌詞。SRT 只提供與本段重疊的區間及本段時間；9B 沒有聽取音訊，不能靠強弱資訊辨識歌詞或副歌。H3 仍用原來裁切的音訊驅動。

移除新流程的每段 160 英文單字上限。原生指南的六區塊與詳細分鏡是拍攝表達，不是額外審查關卡；程式不檢查鏡數、六區塊完整性、全員到齊或敘事好壞。只處理非空交稿與有效媒體引用。失敗時不退回完整故事充當當段稿。

啟用動態切鏡時，自主安排場景內視點及跨場景蒙太奇，不設最低鏡長、固定切點或鏡數；關閉時偏向長鏡。先選擇事件覆蓋，再對入鏡演唱者使用半身或更近景別，避免把整段固定在主唱臉上。原生稿生成後不附加導演、角色、範圍規章。

## 圖片、收尾與重拍

圖片欄位固定，不因角色退場遞補。接續版實際加入前段末幀時，Python 將原圖標記整體偏移一位，Picture 1 專屬末幀；不猜測或重排角色。參考圖不代表所有角色必須入鏡。

full 按真實分段提前預留收束窗口與末尾停留，由規劃器分配結局，當段導演負責拍出。極短尾段延續已開始的收尾。excerpt 可完成局部事件，不強製整首謝幕。

每段完整 prompt 在 H3 採樣前保存。失敗續跑跳過完成影片，保存的 prompt 直接重用；尚未寫稿的段落才呼叫當段導演。丹藥回爐沿用原 prompt、換 Seed，不重分故事或重寫稿。舊 schema 3／4 專案依保存的流程續跑，新任務才用新流程。

原曲 lock_source、最後混音一次、無聲毛片、影格切段、H3 採樣、注意力與 LoRA 維持既有行為。

## 驗證範圍

測試涵蓋規劃快取、當段隔離、原生指南、圖片偏移、完整稿不截短、交稿失敗、worker 中斷續跑與既有回爐流程。9B 和 GPU 在測試中被模擬；實際分戲、分鏡與成片品質仍需新 Colab 任務實測。


## 動態剪輯與重複事件修正

動態切鏡啟用時，積極設計場景內多視點覆蓋及跨場景剪接；每次實際切鏡寫成獨立 Shot 與本段時間碼。推近、平移及人物走近不算切鏡。高動態也要求景別、視點與剪輯變化；保留完整動作、必要停頓及明確長鏡要求，不設最低鏡長或固定鏡數。

分段分配保留原有雙線架構，強調一次性事件只發生一次，短尾段承接既有結局。交稿若出現去除 Mode 與空白後完全相同、至少 200 字元的長事件區塊，使用既有重試流程重新分配；不自行刪除、補寫或合併段落。短段重複停留允許；這不是語意重複判斷。舊計畫及已儲存提示詞仍沿用，完整修正須建立新任務。

測試驗證指令路由、雙線與參考綁定保留、重複稿重試及短停留；模擬模型回傳不代表真實 9B 或 H3 的攝影品質已驗證。

## 每鏡攝影決策交稿

先設計表演、動作細節、反應與環境之間的視覺關係，再以正向必填決策落實每個 Shot：時間與承接、主體及動作結果、鏡位角度景別與透視、主體比例及前後景空間、固定或具體運鏡、光線方向與品質。運鏡說清起始構圖、路徑、速度、幅度與結束構圖，逐鏡形成可見的畫面變化。時間分配在內部完成，最終仍使用 H3 原生 Shot／切點語法，第一鏡無時間碼，其餘鏡頭以切點開始；不增欄位、不輸出表格、不添加第二次模型審查。這是模型交稿要求，程式不以關鍵字判斷攝影品質，真實服從程度需 GPU 實測。


## 自由導演權限分流

`story_plan` 開啟時，上下游同時取得 FREE 政策：沿主軸主動創作視覺事件、表演、互動、反應、環境與蒙太奇，不需使用者先指定攝影技巧。一般拍法描述可重新導演，明確指定必須的鏡頭、角色、聲線、地理、因果里程碑及結果仍保留。關閉時兩階段均取得 FAITHFUL 政策，保留原事件與順序，以攝影轉譯呈現。兩者都交付原生 H3 每鏡精準拍攝稿，維持雙線隔離與當段範圍。上游現在收到 intensity 與 dynamic_cuts；不調整採樣參數或 H3 工作流。舊計畫可依原輸入指紋續跑，不重新分配已保存事件；新策略的完整驗證須建立新任務。測試驗證權限傳遞、當段隔離與原生交稿，不代表真實模型品質已通過。

## 攝影強度與實作依據

自然使用克制表演、觀察視角與細微運鏡；高動態主動設計強烈鏡位、透視縱深、具體運動、塑形光線與節奏剪輯；電影級爆發進一步放大尺度、距離、移動、光影及表演反差。三者均需逐鏡精準交稿。完整強度文字同時交給全片規劃與當段導演，避免上游只有名稱；重試亦保持原強度和改編政策。移除共用的平光／靜止鼓勵，以及爆發模式預設平衡長鏡的引導；明確長鏡要求、動態切鏡開關、因果與收尾仍有效。

## 身分參考與表情表演

兩階段共用身分／表演規則：參考圖及表情表只定義角色身分與外觀，表情示範不是情緒範圍上限。9B 依當段事件、聲部分配、已提供的音樂資訊與強度，設計眼神、眉眼、下顎張力、頭頸及身體反應的變化；暴怒段需具體演出情緒，不能只保持一張生氣參考臉。明確指定的表演要求仍優先。subject_definitions 記穩定身分，Shot 寫動態表演，retention_analysis 不把來源表情／姿勢宣稱為全程固定。實際首尾幀只約束邊界影格。音訊驅動與參考圖片管線不變；此修正不代表已驗證 RH 內部實作或 H3 最終表情品質。
